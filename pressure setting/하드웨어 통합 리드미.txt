하드웨어 리드미

1. 환경 준비
Raspberry Pi 전원을 켜고 인터넷 연결 확인

DHT22는 GPIO 16번에 연결 (3핀: VCC, GND, Signal)

Dynamixel XM430은 USB 포트를 통해 연결 (예: /dev/ttyUSB0)

2. 필요한 패키지 설치
sudo apt-get update
sudo apt-get install python3-pip
pip3 install Adafruit_DHT influxdb dynamixel-sdk
3. InfluxDB 서버 연결 정보 확인
InfluxDB 서버 주소: 172.18.73.63

포트: 8086

사용자명: pi

비밀번호: simple2018

데이터베이스 이름: solutionist

서버가 동작 중이어야 데이터 저장이 가능하며, 없을 경우 측정 가능

4. 코드 실행
python3 dy.py
실행 직후 다음과 같은 작업이 자동으로 진행됩니다:

InfluxDB 서버 연결 및 DB 존재 여부 확인 후 생성

DHT22 센서 스레드 시작 → 온습도 실시간 측정

Dynamixel 스레드 시작 → 각도 이동 + 전류·속도·압력 계산

실시간 데이터 InfluxDB 전송 및 터미널 출력

5. 운영 중 상태 확인
터미널 출력 메시지로 측정 데이터 및 InfluxDB 전송 성공 여부 확인

6. 종료 시
Ctrl + C 입력 → 🛑 통합 센서 시스템 종료 중... 메시지 출력

센서 스레드 안전 종료 및 Dynamixel 토크 해제

InfluxDB 연결 종료
